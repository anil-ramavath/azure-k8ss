# AKS Cluster Reusable Terraform Module & Sandbox Automation

A production-ready, reusable Terraform configuration and module designed to deploy an Azure Kubernetes Service (AKS) cluster matching your exact specifications (`k8ss`) in the **Central India** region with a single command:

```powershell
terraform init && terraform apply
```

This configuration features **automated sandbox discovery**: when working with ephemeral Azure sandbox environments (where resource groups get provisioned with dynamic names like `1-20d54321-playground-sandbox`), the script automatically detects and attaches to the active sandbox resource group without any manual input or hardcoded edits.

## Quickstart: Deploy in 1 Step

Whenever your sandbox refreshes or you need to launch a new cluster:

```powershell
cd c:\Users\anilk\OneDrive\Desktop\k8s
terraform init
terraform apply -auto-approve
```

Terraform will:
1. Run `get_sandbox_rg.ps1` to automatically locate your active sandbox resource group (e.g. `1-20d54321-playground-sandbox`).
2. Pass the resource group and configuration to `modules/aks`.
3. Provision the AKS cluster in `centralindia`.
4. Output the exact command to connect `kubectl`.

---

## Connecting to Your Cluster

Once `terraform apply` finishes, fetch your cluster credentials using the generated output:

```powershell
# Run the command generated by Terraform output:
$(terraform output -raw kube_config_command)

# Verify cluster nodes:
kubectl get nodes -o wide
```

## Customizing Configurations

You can override default parameters either via CLI `-var` flags or by creating a `terraform.tfvars` file:

### Example `terraform.tfvars`
```hcl
subscription_id    = "your-subscription-id"
cluster_name       = "custom-aks"
location           = "centralindia"
vm_size            = "Standard_DS3_v2"
min_count          = 3
max_count          = 6
kubernetes_version = "1.36.5"
```

### Or using an explicit Resource Group (skipping auto-discovery)
```powershell
terraform apply -var="resource_group_name=my-explicit-rg"
```

## Reusing the AKS Module in Other Projects

You can directly reference `modules/aks` in any other repository or root configuration:

```hcl
module "aks" {
  source = "./modules/aks" # Or "git::https://github.com/..."

  cluster_name        = "production-cluster"
  resource_group_name = "rg-production"
  location            = "centralindia"
  dns_prefix          = "prod-aks-dns"
  kubernetes_version  = "1.36.5"

  vm_size              = "Standard_D4s_v5"
  node_count           = 3
  auto_scaling_enabled = true
  min_count            = 3
  max_count            = 10

  oidc_issuer_enabled       = true
  workload_identity_enabled = true
}
```
